# OpsForge

OpsForge is an AI-powered Platform Engineer hackathon scaffold.

## Purpose

This repository is intentionally minimal. It defines the project layout for a React, FastAPI, MongoDB Atlas, Gemini, DigitalOcean, and ElevenLabs based prototype without implementing business logic or integrations.

## Structure

- `frontend/` contains the React + Vite + TypeScript app scaffold.
- `backend/` contains the FastAPI app scaffold.
- `demo-app/` contains a placeholder demo application.
- `infra/` contains infrastructure placeholders.
- `docs/` contains planning and presentation notes.
- `scripts/` contains local development helper placeholders.
